<section id="basicsPage" class="page-section hidden">
<div class="section-heading">
<h2>Об игре</h2>
<p>Коротко о цели матча, карте, ролях и предметах.</p>
</div>

<div class="info-grid">
<article class="info-box">
<h3>Что такое Dota 2?</h3>
<p>
Dota 2 — командная игра, в которой две команды по пять игроков
сражаются на одной карте. Каждый игрок выбирает героя с уникальными
способностями. Главная цель — уничтожить главное строение
противника, которое называется Древним.
</p>
</article>

<article class="info-box">
<h3>Цель матча</h3>
<p>
Чтобы добраться до Древнего противника, команда продвигается по
линиям, сражается с героями и разрушает вражеские строения. При этом
нужно защищать свою базу и помогать союзникам.
</p>
</article>

<article class="info-box">
<h3>Три линии</h3>
<p>
На карте есть верхняя, центральная и нижняя линии. По ним движутся
союзные и вражеские крипы. Побеждая крипов и участвуя в игре,
герой получает золото и опыт.
</p>
</article>
<article class="info-box">
<h3>Золото и предметы</h3>
<p>
За золото герой покупает предметы. Они могут усиливать героя,
помогать перемещаться, восстанавливать здоровье и ману или давать
полезные активные способности.
</p>
</article>

<article class="info-box">
<h3>Основные роли</h3>
<ul>
<li><strong>Керри</strong> — обычно становится сильнее по мере получения уровней и предметов.</li>
<li><strong>Мидер</strong> — чаще всего играет на центральной линии и может помогать другим линиям.</li>
<li><strong>Оффлейнер</strong> — создаёт давление на противников и часто помогает начинать сражения.</li>
<li><strong>Поддержка</strong> — помогает союзникам и заботится об обзоре карты.</li>
</ul>
</article>

<article class="info-box">
<h3>Мини-карта</h3>
<p>
Мини-карта показывает важные области поля боя. Периодически
поглядывай на неё: так проще заметить опасность или понять, где
нужна помощь союзникам.
</p>
</article>
</div>

<div class="notice">
Dota 2 регулярно обновляется: способности и характеристики предметов
могут меняться. В этом учебном гайде приведены общие объяснения, а не
точные данные конкретного игрового обновления.
</div>
</section>

<section id="tipsPage" class="page-section hidden">
<div class="section-heading">
<h2>Советы новичкам</h2>
<p>Несколько простых привычек, которые помогут освоиться в игре.</p>
</div>

<div class="info-grid">
<article class="info-box">
<h3>Начни с небольшого выбора</h3>
<p>
Выбери несколько героев, которые тебе нравятся, и сначала изучи их
способности. Так будет легче понять, что делать в разных ситуациях.
</p>
</article>

<article class="info-box">
<h3>Следи за мини-картой</h3>
<p>
Периодически смотри, где находятся союзники и заметные противники.
Это помогает вовремя заметить опасность и не оставаться одному.
</p>
</article>

<article class="info-box">
<h3>Помогай команде</h3>
<p>
Dota 2 — командная игра. Делись важной информацией, помогай
союзникам и старайся выбирать общие цели вместе с командой.
</p>
</article>

<article class="info-box">
<h3>Изучай предметы</h3>
<p>
Не обязательно сразу запоминать все предметы. Начни с нескольких
базовых и обращай внимание на то, как они помогают выбранному герою.
</p>
</article>

<article class="info-box">
<h3>Ошибки — часть обучения</h3>
<p>
В начале легко растеряться или ошибиться. После матча подумай, что
получилось хорошо и что можно попробовать сделать иначе в следующий
раз.
</p>
</article>

<article class="info-box">
<h3>Сохраняй спокойствие</h3>
<p>
В напряжённой игре легко расстроиться. Спокойное общение и
взаимопомощь обычно полезнее споров и обвинений.
</p>
</article>
</div>

<div class="notice">
Совет для первого знакомства: сыграй несколько матчей за одного и того
же героя, чтобы привыкнуть к его способностям и управлению.
</div>

const cardsGrid = document.getElementById("cardsGrid");
const searchInput = document.getElementById("searchInput");
const roleFilter = document.getElementById("roleFilter");
const pageTitle = document.getElementById("pageTitle");
const pageDescription = document.getElementById("pageDescription");
const catalogPage = document.getElementById("catalogPage");
const basicsPage = document.getElementById("basicsPage");
const tipsPage = document.getElementById("tipsPage");

let currentPage = "heroes";

function renderCards() {
const searchText = searchInput.value.trim().toLowerCase();
const selectedRole = roleFilter.value;
const data = currentPage === "heroes" ? heroes : items;
const filtered = data.filter(function (entry) {
const searchableText = (
entry.name + " " +
entry.russian + " " +
entry.subtitle + " " +
entry.description
).toLowerCase();

const matchesSearch = searchableText.includes(searchText);
const matchesRole =
currentPage === "items" ||
selectedRole === "all" ||
entry.roles.includes(selectedRole);

return matchesSearch && matchesRole;
});

cardsGrid.innerHTML = "";

if (filtered.length === 0) {
cardsGrid.innerHTML =
'<div class="empty-message">Ничего не найдено. Попробуй изменить запрос или фильтр.</div>';
return;
}

filtered.forEach(function (entry) {
const card = document.createElement("article");
card.className = "card";

let tags;

if (currentPage === "heroes") {
tags = entry.roles.map(function (role) {
return '<span class="tag">' + role + '</span>';
}).join("");
} else {
tags = '<span class="tag">' + entry.subtitle + '</span>';
}

card.innerHTML = `
<div class="card-top">
<div class="icon" aria-hidden="true">${entry.icon}</div>
<div>
<h3>${entry.name}</h3>
<div class="subtitle">${entry.russian} · ${entry.subtitle}</div>
</div>
</div>
<p>${entry.description}</p>
<div class="tags">${tags}</div>
<button class="card-button" type="button">Подробнее →</button>
`;

card.querySelector(".card-button").addEventListener("click", function () {
alert("Нажатие сработало");
  const type = currentPage === "heroes" ? "Герой Dota 2" : "Предмет Dota 2";
  openDetail(entry, type);
});

cardsGrid.appendChild(card);
});
}

function openDetail(entry, type) {
  document.getElementById("detailType").textContent = type;
  document.getElementById("detailTitle").textContent =
    entry.name + " — " + entry.russian;

  document.getElementById("detailContent").innerHTML = `
    <p><strong>${entry.subtitle}</strong></p>
    <p>${entry.detail}</p>
    <p><strong>Кратко:</strong> ${entry.description}</p>
  `;


document.getElementById("detailPanel").classList.add("open");
}

function closeDetail() {
document.getElementById("detailPanel").classList.remove("open");
}

function showPage(page) {
currentPage = page;

catalogPage.classList.add("hidden");
basicsPage.classList.add("hidden");
tipsPage.classList.add("hidden");

if (page === "basics") {
basicsPage.classList.remove("hidden");
return;
}

if (page === "tips") {
tipsPage.classList.remove("hidden");
return;
}

catalogPage.classList.remove("hidden");
searchInput.value = "";
roleFilter.value = "all";

if (page === "heroes") {
pageTitle.textContent = "Герои Dota 2";
pageDescription.textContent =
"Выбирай героя, читай краткое описание и знакомься с его ролью.";
roleFilter.classList.remove("hidden");
} else {
pageTitle.textContent = "Предметы Dota 2";
pageDescription.textContent =
"Знакомься с предметами и узнавай, для чего они могут пригодиться.";
roleFilter.classList.add("hidden");
}

renderCards();
}

document.querySelectorAll(".nav button").forEach(function (button) {
button.addEventListener("click", function () {
document.querySelectorAll(".nav button").forEach(function (navButton) {
navButton.classList.remove("active");
});

button.classList.add("active");
showPage(button.dataset.page);
});
});

document.getElementById("closeDetail").addEventListener("click", closeDetail);

document.getElementById("detailPanel").addEventListener("click", function (event) {
if (event.target.id === "detailPanel") {
closeDetail();
}
});
document.addEventListener("keydown", function (event) {
if (event.key === "Escape") {
closeDetail();
}
});

searchInput.addEventListener("input", renderCards);
roleFilter.addEventListener("change", renderCards);

renderCards();
</script>
